Lesson 1

What is CSS? (Overview & Benefits)

Definition

CSS stands for Cascading Style Sheets. It describes how HTML elements are displayed on screen, paper, or other media. CSS separates content (HTML) from design, simplifies maintenance, and can control the layout of multiple pages at once.

Why use CSS?

  • CSS is used to define styles for your web pages, including the design, layout and variations in display for different devices and screen sizes.
  • Provides consistency across web pages and saves time: one CSS file can control multiple pages.
  • Improve accessibility and responsiveness.
  • Enhance design with layouts, colors, and animations.

Layers of a Webpage

Each layer of the webpage has its specific use or function inthe web page. Each plays an important role to be able to attain the goal or objective of a particular website.

  1. Content Layer HTML: text, images, video, structured content, accessible alt text and clear phrasing. (Guidelines: KISS, readable headings/paragraphs, alt text for images.)
  2. Presentation Layer CSS: controls how users see the page. Ensure zoomability, contrast (colorblind-friendly), consistent navigation, and separation into understandable units.
  3. Behavior Layer JavaScript or scripting: real-time interactions, validation, dynamic experiences. Make sure functionality is available regardless of input device.

Benefits & Capabilities

  • Easy maintenance — change one stylesheet, update entire site.
  • Faster page loading and more flexible design.
  • Position and layer objects precisely, create custom tags and reusable styles.

Prerequisite

Basic knowledge of HTML/XHTML before learning CSS.

Style Sheets: Structure & Types

Structure of a CSS rule

A CSS rule is composed of:

  • Selector — the HTML element you want to style; is a pattern used to "find" or "select" the HTML elements on a webpage to which a set of CSS rules will be applied.
  • Declaration — is a single instruction that defines a specific style for an element
  • Declaration block – fundamental part of a CSS rule. It is a block of code that contains one or more CSS declarations, which define the styling rules for the selected HTML element(s).
  • Property — the style attribute you want to modify; is a named characteristic or attribute that defines a specific aspect of how an HTML element should be displayed or rendered by the browser. Properties are used within CSS declarations to apply styles to selected elements.
  • Value — the weight of the attribute you want to apply to the element property; is the specific setting or configuration assigned to a CSS property. A property and its value form a CSS declaration, which dictates how an element should be styled

    Applying CSS to HTML Documents

    Cascading Style Sheets (CSS) can be applied to a webpage through three main methods:inline, internal (embedded), and external style sheets.Inline CSS involves directly writing style rules within an HTML element using thestyle attribute. For example: 

    <p style="color: green; font-size: 18px;">This paragraph uses inline CSS.</p>

    Internal or embedded CSS is placed inside a <style> tag within the <head> sectionof an HTML document, allowing multiple elements in the same page to share consistent formatting:

    <style>
h1 { color: red; text-align: center; }
p  { font-size: 18px; color: purple; }
</style>

    External CSS uses a separate .css file linked to the HTML page with <link rel="stylesheet" href="style.css">. This method is most efficient for sites with multiple pages because editing one stylesheet updates them all.

    The display property defines how elements appear and behave. Two major element types exist: block-level and inline-level. Block-level elements (like <p>, <div>, <section>, <article>,<ol>, <ul>, and headings <h1>–<h6>) take the full width and start on new lines, stacking vertically. Inline elements (like <a>, <strong>, <em>, <b>, <i>, <q>, <mark>, and <span>) sit side by side horizontally and don’t begin on new lines.

    Inline elements can’t contain block-level ones. For instance, <em> cannot wrap around multiple paragraphs, but it can sit inside one: 

    <p><em>Example text</em></p>

    The display property can modify default behavior: display: inline; keeps items horizontal, display: block; stacks them vertically, display: list-item; mimics list behavior, display: none; hides elements, and display: inherit; copies the parent’s display value. For example: 

    p { display: inline; }
span { display: block; }

    Structuring webpages often involves the <div> and <span> tags. Both are generic containers with no visual effect until styled with CSS. <div> is block-level and used to group larger sections of a page: 

    <div class="section1">This is a styled section.</div>

    <span> is inline and best for styling small portions of text: 

    <p>This <span style="color:red;">word</span> is emphasized.</p>

    Both tags work powerfully with CSS classes via the class attribute. For example: 

    <div class="highlight">Sample text</div>

.highlight { background-color: yellow; }

    In summary, Lesson 3 highlights how different stylesheet methods(inline, internal, and external) influence page design; how thedisplay property defines layout; how block-level and inline elements behave; and how <div> and <span> serve as flexible containers for organizing and styling content effectively across web pages.

    CSS Rules, Classes, and Grouping Selectors

    A CSS rule is the foundation of every style sheet. It tells the browser which elements to style and how to style them. A rule consists of two parts: the selector, which identifies the HTML element to be styled, and the declaration block, which contains one or more style declarations written inside curly braces { }.

    p {color: red;
font-size: 18px;}

    In this example, the selector p targets all paragraph elements, and the declarations define their color and font size. Each declaration includes a property (such as color) and a value (such as red), separated by a colon and ending with a semicolon.

    There are six main groups of style properties used in CSS:

    • Fonts — define the typeface, size, and weight of text. 
      p { font-family: Arial; font-size: 16px; }
    • Colors and Backgrounds — control the visual appearance and background of elements. 
      body { background-color: black; color: white; }
    • Text — manage alignment, decoration, and spacing. 
      h1 { text-align: center; text-transform: uppercase; }
    • Boxes and Layout — determine how elements are positioned on the page. 
      div { margin: 20px; padding: 15px; border: 2px solid red; }
    • Lists — modify bullets, numbering, and list spacing. 
      ul { list-style-type: square; }
    • Tag Classifications — control how elements behave or are categorized. 
      img { display: block; }

    CSS also allows developers to define reusable styles through classes. A class is a custom name that can be applied to any element using the class attribute in HTML. Classes are declared in CSS using a period (.) before the class name. For example: 

    p.golden { color: blue; }
.sodapop { color: red; }

    In the HTML file, you can call these classes like this: 

    This paragraph text is blue.
    

    This div text is red.

    You can also assign multiple classes to one element for combined effects: 

    This text is both highlighted and large.
    
  
    .highlight { background-color: yellow; color: black; }
.big-text { font-size: 24px; font-weight: bold; }

    The class selector (.classname) applies to any element with that class, while the element + class selector (element.classname) is more specific and only affects that particular HTML tag. Example: 

    .note { background-color: yellow; }
p.note { color: blue; }

    Here, .note affects all elements using the class note, but p.note only styles paragraphs that use that same class. Example in HTML: 

    This is a styled paragraph.

    Another important concept is the grouping selector, which lets you apply the same styles to multiple selectors at once by separating them with commas. This reduces repetition and keeps code clean. For example: 

    h1, p { color: white; background-color: black; }

    This rule applies the same color and background to both headings and paragraphs. Grouping selectors ensure consistency and efficiency across multiple elements, allowing designers to write shorter and more organized stylesheets.

    In summary, Lesson 4 emphasizes that each CSS rule follows the structure of a selector and a declaration block, while style properties are categorized into six major groups. Classes enable reusable, flexible styling; element-plus-class selectors add precision; and grouping selectors make your code cleaner and easier to maintain.
